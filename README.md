# Neon Blade (mobile)

2D neon action platformer for Android, made in Unity 6 (6000.6) for Game Development Fundamentals, Narxoz University.
Run, jump and dash through enemies. An enemy flashes white and charges up before it strikes: dash through it to kill it.

**Controls (touch):** ◀ ▶ move · Jump · Attack (dash) · Pause button (top).

## Sound (week 12)

| Event | When it plays | File(s) | Group |
|---|---|---|---|
| jump | player jumps | `jump_1..3` | SFX |
| land | player lands after a fall | `land_1` | SFX |
| dash | attack / dash starts | `dash_1..2` | SFX |
| hit | an enemy is killed by the dash | `hit_1..3` | SFX |
| pickup | player collects a crystal | `pickup_1..2` | SFX |
| enemy alert | an enemy sees the player (patrol → chase) | `alert_1` | SFX |
| **enemy wind-up** | **start** of the enemy attack wind-up, before the strike lands | `windup_1` | SFX |
| death | player is hit | `death_1` | SFX |
| lose | right after death, before the level restarts | `lose_1` | SFX |
| win | room cleared (last enemy killed) | `win_1` | SFX |
| UI click | any menu button | `click_1..2` | UI (child of SFX) |
| menu music | main menu, loop | `music_menu` | Music / Tracks |
| level music | game scene, loop | `music_level` | Music / Tracks |

Repeated sounds get a random pitch 0.92–1.08 and alternate between 2–3 versions.

**Mixer** `Assets/Resources/GameMix.mixer`: Master → Music → Tracks, Master → SFX → UI.
Exposed: `MasterVol`, `MusicVol`, `SFXVol`. Snapshots: `Normal` and `Paused` (Tracks −6 dB, Lowpass 800 Hz).

**Scripts** (`Assets/Scripts/Audio`):
- `AudioManager`: created before the first scene, `DontDestroyOnLoad`, owns all AudioSources, plays events by name, picks scene music, adds click sounds to menu buttons.
- `MusicManager`: two looping sources, 1 s equal-power crossfade, the same track never restarts on a level reload.
- `VolumeSettings`: slider value → decibels (`Log10(v) × 20`), values stored in `save.json` (the week 11 save system).
- `SettingsPanel`: the Master / Music / SFX slider panel, used in the main menu and in pause.
- `PauseMenu`: `Time.timeScale = 0` + Paused snapshot.
